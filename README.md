## Projects

### 🤖 [Data Analyst Agent](https://github.com/GouravSoniya/Data-Analyst-Agent)
CLI agent that takes any CSV and answers questions about it in plain English.
Writes and executes Python code in a sandboxed environment — no hallucinated answers.
Supports LM Studio (fully local) and Groq.

### 🎫 [Support Agent](https://github.com/GouravSoniya/support-agent)
AI-powered support ticket processor built with FastAPI + Inngest + Groq.
Classifies tickets, drafts replies, and saves to SQLite — with automatic retries
and step-level checkpointing via Inngest.
